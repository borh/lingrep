# lingrep 0.3.1

The macOS archive in 0.3.0 starts only when Homebrew `xz` is installed:

```text
dyld: Library not loaded: /opt/homebrew/opt/xz/lib/liblzma.5.dylib
```

0.3.1 links liblzma statically, so `ling` for `aarch64-apple-darwin` loads
only system libraries. The Linux archives were not affected. Nothing else
changes: catalogs, prepared corpora and output are the same as in 0.3.0.

See the [0.3.0 release notes](v0.3.0.md) for what lingrep includes, and the
[README](../../README.md) for installation.
