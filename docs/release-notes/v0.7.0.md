# lingrep 0.7.0

Run the browser interface from the CLI release archives:

```bash
ling serve --help
```

`ling serve` takes the same arguments as `lingrep-web`. The default `web`
feature includes it; `--no-default-features` builds the CLI without it.
An occupied port produces an invocation error with exit code 2.

Build reusable frequency tables and browse them in the browser:

```bash
ling summarize --corpus works.lingcorpus --patterns patterns/collexeme.lx \
  --write-table works.lingtable
ling serve --corpus works=works.lingcorpus --pattern-root patterns \
  --count-table works.lingtable
```

Frequencies shows counts, document metadata filters, entry profiles and
concordance lines. Compare ranks entries between two document scopes by G².
`ling table` and `ling contrast` provide the corresponding CLI results.
The workbench capture-key picker runs fresh CLI summaries for `text`, `lemma`
and `norm` projections without changing saved tables.

JSON consumers must replace `complete.data.counters.tokens_matched` with
`complete.data.counters.tokens_scanned`; there is no compatibility alias.
It counts tokens in scanned sentences, excluding sentences proven absent.
`summarize --by-section` and `--by-metadata @document.KEY` add section and
metadata-value counts to query/v2 output.
The query/v2 `run` record adds `matcher_semantics_identity`, and
`ling --json check` adds `capture_key_edits` to its `lingrep.check/v1` record.

`ling corpus render` writes Markdown reading sidecars. Serve them with
`ling serve --reading-sidecar PATH` to read documents with their Markdown
headings and paragraphs. Selecting a line of a Frequencies entry opens its
occurrence in the document; closing the reader returns to the line. The URL
preserves the open reader, and corpora without a sidecar retain the
artifact-based reading view.

Markdown analysis excludes marked LaTeX math; conversion-artifact recovery
preserves significance asterisks before p-value comparisons. Rebuild existing
Markdown artifacts to apply these reader changes.

The Soranoha readers store `@document.ndc` as a list of NDC class codes, so
`NDC 712 914` becomes `["712", "914"]`. Rewrite `@document.ndc = "NDC 913"` as
`@document.ndc contains "913"`. Soranoha artifacts built with 0.7.0 have new
analysis identities; rebuild an existing one to query `ndc` as a list.

Lookarounds can read neighbouring sentences within a document or an authored
division, such as a paragraph or section:

```text
pattern next_noun := [] $ followed_by(^ [upos=NOUN], within=document).
```

A scoped body must have a maximum width and cannot contain another lookaround.
A window ends at a sentence removed by scope filtering, sampling, or an
oversized-sentence skip. Retained context counts toward the tokenized byte
limit, including empty sentences; execution fails if the required window
exceeds it. Anchor exclusion fragments cannot contain scoped lookarounds.
CLI scans, the browser, and explore support these windows.

A `where` clause accepts `$a < $b < $c` to constrain node order. Basic graph-node
binders select distinct words, including words distinct from surface captures
named by a basic edge. Queries that relied on repeated assignments can return
fewer matches.

Other additions include `skip:` tests, declared attribute label sets,
`summarize --by-document`, an `artifact_path` field in corpus build and inspect
JSON, and SVG diagram export to a directory. `skip` and `labels` are reserved
words. Direct runs preserve in-document ordinal gaps after scope filtering,
as prepared runs do. `ling --json check --diagram` rejects the incompatible
output modes.

Adapter wheels use version 0.7.0. Existing analyzer bundles remain usable;
preparing a bundle with the new wheels changes its analyzer identity and the
identities of corpora prepared with it. See the
[changelog](../../CHANGELOG.md#070---2026-11-10) for the complete release changes.
