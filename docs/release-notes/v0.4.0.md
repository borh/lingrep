# lingrep 0.4.0

`ling` can now download its own UniDic dictionary:

```bash
ling dictionary install
ling matches --pattern '[upos=VERB].' sample.txt
```

`ling dictionary install` downloads the CWJ dictionary (412 MB), checks its
BLAKE3 digest, and installs it under `~/.local/share/lingrep/dictionaries`.
`ling` uses it when neither `--dict-path` nor `LINGREP_DICTIONARY_PATH` names a
dictionary. Six more UniDic dictionaries, for spoken, literary and historical
Japanese, install by name; [DICTIONARIES.md](../../DICTIONARIES.md) lists them
and their licenses. The Nix packages download the same files instead of
converting UniDic.

Also in this release:

- Sudachi analysis uses sudachi.rs 0.7.0 and needs only `--sudachi-dict`;
  resources, split mode and edition have defaults. It reads SudachiDict
  v20261015 or later from SudachiDict's GitHub releases page. Sudachi corpora
  prepared with 0.3.x must be rebuilt.
- `ling corpus variants --prune` deletes prepared corpora that were written in
  an earlier format than this `ling` reads. Without `--prune`, the command
  lists them with their sizes.
- A prepared corpus written by a newer `ling` is refused with an error that
  names the unknown field and both versions.
- `install.sh` installs the manual pages and shell completions, following the
  XDG Base Directory Specification.

UniDic and CoNLL-U corpora prepared with 0.3.x, catalogs, and the pattern
language are unchanged. The [changelog](../../CHANGELOG.md) lists every change.
