# lingrep 0.3.2

0.3.2 adds two ways to get `ling`:

- An archive for Intel Macs, `ling-0.3.2-x86_64-apple-darwin.tar.gz`, beside
  the Apple silicon and Linux archives.
- `install.sh`, which installs this release's `ling` for the computer it runs
  on:

  ```bash
  curl --proto '=https' --tlsv1.2 -fsSLO https://github.com/borh/lingrep/releases/latest/download/install.sh
  sh install.sh
  ```

  It checks the archive's SHA-256 checksum, copies `ling` to `~/.local/bin`,
  and adds that directory to `PATH` in the shell's startup file when it is
  not already there. The [README](../../README.md#install-script) lists its
  options.

Nothing else changes: catalogs, prepared corpora and output are the same as in
0.3.1.

See the [0.3.0 release notes](v0.3.0.md) for what lingrep includes.
