# lingrep 0.5.0

This release adds TEI search, reusable external-analyzer setup, and corpus
inspection in the web interface. CLI help is shorter, long sentences use
singleton batches automatically, and `tokenize --limit` limits sentence output.

## Upgrading from 0.4.0

Rebuild NFC prepared corpora whose manifests omit the normalization-table version
or record a version other than Unicode 18. The table version is part of reader
and analyzer identity, so those artifacts cannot be reused.
Markdown front matter also uses a revised parser that rejects duplicate keys;
rebuild Markdown corpora to use the revised reader.

Artifacts with a nonzero recorded truncation count are rejected for execution
and reuse. Rebuild those artifacts from source as well. Dictionary bytes and the
pinned Vibrato and Sudachi runtime engine revisions are unchanged.

Use `matches` or `summarize` with `patterns/sentence-final.lx` in place of the
removed sentence-final command. Rust callers should compile definitions through
`FsmBuilder` and use `CompiledCatalog`; raw-map compatibility APIs and public
mutable NFA construction have been removed.

## TEI text and annotations

`--input-format tei` reads supported TEI P5 XML files or directories;
`--input-format soranoha-tei` reads Soranoha TEI archives. Soranoha TEI produces
the same principal text and sentence boundaries as its paired plaintext edition.
Inline readings and markup are available through `tei.ruby`, `tei.element`,
`tei.rend` and `tei.source`, including in prepared corpora. The
[CLI guide](https://github.com/borh/lingrep/blob/v0.5.0/docs/cli-usage-guide.md#soranoha-bulk-archives) describes the reading policy
and supported TEI subset.

## Other changes

- Configure verified spaCy and Stanza analyzers once and reuse their sealed
  bundles. The adapter wheels include setup tools; Nix packages an English
  spaCy CPU model and analyzer configuration.
- Scope web analysis by section, inspect compounds and overlapping matches,
  compare sections, count documents, sort KWIC results, and read bounded
  paragraph or document context. Exports and shared links preserve scope.
- Use `--help-all` for advanced CLI controls. Terminal concordances preserve
  source spacing, and progress appears automatically on terminal stderr.
- Long sentences use singleton batches within the documented resource limits;
  Sudachi chunks long input while preserving original sentence offsets.
- Prepared-corpus builds collect postings while writing tokens, avoiding a
  reconstruction pass without changing artifact bytes or identities.
- Dependency-pattern exclusions and set-operand ordering are corrected.
  Dependency updates address RustSec findings and remove unmaintained packages,
  including vulnerable zstd dependencies in the runtime, fuzz and converter graphs.
- Dictionary installations include upstream license and attribution files.

See the [installation guide](https://github.com/borh/lingrep/blob/v0.5.0/docs/installation.md) for archives, Nix and analyzer
setup, and the [changelog](https://github.com/borh/lingrep/blob/v0.5.0/CHANGELOG.md) for the full release summary.
