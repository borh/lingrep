# lingrep 0.3.0

The first public release of lingrep.

## What it includes

- `ling`, a command-line tool that tokenizes Japanese text or reads analyzed
  text, matches lingrep patterns, aggregates matches exactly, and prints
  concordances.
- The lingrep patterns language: token tests, `set` and `test` declarations,
  `&` intersection, `any_order`, lookaround, inline lexicons, named projection
  keys, `where` clauses over dependency edges, enhanced-graph constraints, and
  a publication `policy … end` block.
- Input readers for plain text, JSONL, the pandoc Markdown dialect, CoNLL-U,
  BCCWJ distributions and Soranoha archives, with document, sentence and
  division metadata, source offsets, and `--where` scoping.
- Immutable prepared corpora (`.lingcorpus`) for repeated queries.
- `ling explore`, an interactive terminal explorer; `--json` query contracts;
  generated shell completions and man pages.
- `lingrep-web`, a multi-corpus web front end with a NixOS module.

## Install

From source with Nix flakes; see the [README](../../README.md) and
[DICTIONARIES.md](../../DICTIONARIES.md):

```bash
nix build .#lingrep          # ./result/bin/ling plus completions and man pages
```

Release archives of `ling` for Linux (x86-64, arm64) and macOS (Apple silicon)
are attached to this release. They include no dictionary. Commands that analyze
Japanese text need one, named by `--dict-path` or `LINGREP_DICTIONARY_PATH`:

- UniDic, the default analyzer (`--analyzer vibrato`): build it with
  `nix build .#vibrato-dict-cwj` and use
  `share/vibrato/unidic-cwj-202512.dic`. Seven UniDic 202512 editions are
  packaged.
- Sudachi, without Nix: use `sudachi-dictionary-20260723-core.zip` or another
  SudachiDict release up to `v20260723`, with the resource files from the
  pinned `sudachi.rs` revision. Sudachi changed its dictionary container after
  `v20260723`, and this build refuses later dictionaries with an error that
  names the container it found. The [README](../../README.md) has the exact
  commands.

CoNLL-U input, `ling check`, `ling describe`, `ling contracts`, and the
completion and man page generators need no dictionary.
