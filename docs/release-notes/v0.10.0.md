# lingrep 0.10.0

lingrep 0.10.0 adds dependency paths and SUD deep features to the pattern
language, compares two match runs with `ling diff`, exports analyzed text as
CoNLL-U, and checks catalogs without a corpus. Definitions that use `&`,
`measure`, or `same_as` publish fewer nested matches than in 0.9, so rebuild
count tables.

```bash
curl --proto '=https' --proto-redir '=https' --tlsv1.2 -fsSLO https://github.com/borh/lingrep/releases/download/v0.10.0/install.sh
sh install.sh
```

Install the Python bindings with `python -m pip install lingrep==0.10.0`.

## Patterns

- `-[+ LABELS]->` matches a path of basic dependency edges, and the first or
  last edge can be tested separately.
  [Basic paths](https://github.com/borh/lingrep/blob/v0.10.0/docs/pattern-language-reference.md#basic-dependency-paths)
- Edge tests match SUD deep features such as `comp:aux@pass` on basic or
  enhanced edges, and `deep(…)` projects them.
  [SUD deep features](https://github.com/borh/lingrep/blob/v0.10.0/docs/pattern-language-reference.md#sud-deep-features-on-dependency-edges)
- `tree(LAYER)` measures dependency trees in a named span layer.
  [Occurrence measurements](https://github.com/borh/lingrep/blob/v0.10.0/docs/pattern-language-reference.md#occurrence-measurements)

## Commands

- `ling diff` compares saved match runs over the same corpus by span, named
  role, or complete record, and writes `lingrep.diff/v1` JSONL.
  [Match comparison guide](https://github.com/borh/lingrep/blob/v0.10.0/docs/cli-usage-guide.md#comparing-two-patterns-occurrences)
- `ling tokenize --output-format conllu` exports direct or prepared input as
  CoNLL-U.
  [CoNLL-U export guide](https://github.com/borh/lingrep/blob/v0.10.0/docs/cli-usage-guide.md#export-an-analyzed-corpus-as-conll-u)
- `ling --json summarize --by-window N` counts occurrences per document-local
  token window and writes `lingrep.window-counts/v1`.
  [Window counts guide](https://github.com/borh/lingrep/blob/v0.10.0/docs/cli-usage-guide.md#counting-per-sentence-aligned-token-window)
- `ling check` reports unsatisfiable token tests and definitions.
  `--containment` compares which spans definitions can publish,
  `--verify-examples` explains failed examples, and
  `--propose-counterexamples FILE` finds sentences that match after one
  constraint is removed.
  [Catalog checks](https://github.com/borh/lingrep/blob/v0.10.0/docs/cli-usage-guide.md#catalogs-and-matching)

## Web

- The Workbench compares the edited pattern with the last search and opens
  differing occurrences in the reader.
- The Sample debugger verifies catalog examples and counterexamples, shows
  which pattern element consumed each token, and can analyze edited text with
  a configured GiNZA, spaCy, Stanza, protocol adapter, or Sudachi analyzer.
  [Live sample analyzer setup](https://github.com/borh/lingrep/blob/v0.10.0/docs/deployment-guide.md#configure-live-analysis-for-the-sample-debugger)
- The Question page groups hits by work, with work totals and source
  positions, and sorts across all indexed hits.
- The web pages have a dark theme, skip links, and Tab navigation between the
  editor and adjacent controls.
- The Japanese interface uses セクション for a document section and no longer
  uses 用例 for a match or a counted occurrence.

## Analyzers

A spaCy or GiNZA transformer model runs on Apple Silicon with
`backend = "mps"`. `lingrep-spacy-setup` selects it by default when the
environment's PyTorch reports MPS available. An analyzer set up for `mps`
fails at startup when MPS is unavailable.
[External analyzer setup](https://github.com/borh/lingrep/blob/v0.10.0/docs/cli-usage-guide.md#use-an-external-protocol-adapter)

## Upgrading

- Rebuild count tables. The matcher revision is `lingrep-core-matcher/v3`, and
  a table written by an earlier release is rejected. A definition that uses
  `&`, `measure`, or `same_as` now drops a span when another span from the
  same definition starts earlier and ends later.
  [Match publication rules](https://github.com/borh/lingrep/blob/v0.10.0/docs/pattern-language-reference.md#which-matches-a-definition-publishes)
- `patterns/sf-experimental.lx` counts overlapping definitions. Pass
  `--overlaps longest` to select one record per overlapping set.
- Rebuild BCCWJ artifacts to restore leading zeros in genre codes.
- Set `--md-recover-conversion-artifacts` when you build a corpus. `ling`
  rejects it with `--corpus`.
- Rust callers of the corpus API read through `PreparedTokenReader` for
  random access and `PreparedSentenceSource` for sequential reads, and
  `MatchSink` implementations declare an associated error type.

Adapter wheels use version 0.10.0. See the
[changelog](https://github.com/borh/lingrep/blob/v0.10.0/CHANGELOG.md#0100---2026-11-24) for the complete list of changes.
