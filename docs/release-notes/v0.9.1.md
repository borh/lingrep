# lingrep 0.9.1

Tokenize Japanese from the command line with `uvx lingrep tokenize '猫が眠る。'`. For a batch, pipe one sentence per line and pass `--workers 4`. Each line of output is a JSON array of token surfaces, in input order.

If you use the default dictionary and it is missing, the tokenizer downloads
and verifies UniDic CWJ (about 1.3 GB on disk). The tokenizer can reuse the
installed dictionary offline. To select your own dictionary, pass `--dict-path` or set
`LINGREP_DICTIONARY_PATH`. Python's `Tokenizer` uses the same lookup. Install
the matching `ling` executable to search corpora from Python.

- Vibrato preserves the original character spans when NFC composes a letter and leaves a trailing combining mark. Rebuild prepared corpora to use the corrected alignment.
- French Stanza bundles can provide tokenization with just the GSD tokenizer and multi-word-token processor.
- Corpus builds that exhaust the process file limit report the I/O error and suggest raising the limit. Positional-window summaries can merge runs under a lower file limit.
