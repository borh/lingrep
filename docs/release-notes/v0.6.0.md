# lingrep 0.6.0

Draw a pattern's recognition flow without a dictionary or corpus:

```bash
ling check --pattern '[upos=NOUN]? [upos=VERB]+.' --diagram
ling check --patterns constructions.lx --diagram --name target \
  --expand --diagram-format svg >target.svg
```

Unicode is the default; `--diagram-format ascii` changes the connectors.
`--width` sets layout columns. Wide expressions continue on connected rows or
use numbered subdiagrams with complete labels. SVG output requires one selected
definition and includes its own styles. Web diagrams follow the application theme,
distinguish intersection from unordered matching, and include every compound
dependency clause.

`--progress auto`, the default, shows no progress for streaming results, JSON,
TSV and redirected stdout. Deferred human output can show a status line after one
second on capable terminals. `--progress always` enables progress;
`--trace-policy 0` prints policy totals, and a positive value also prints
per-record explanations. A query that creates a prepared artifact reports its path
once in every progress mode. Warnings remain visible, and a failed warning write
exits 1.

`doctor --corpus` checks a prepared corpus without loading the default dictionary.
Add `--dict-path` to check a dictionary too. Without `--corpus`, the default
dictionary is checked. Human output summarizes the selected checks; JSON warnings
use the diagnostic stream. A repeated dictionary check reuses the cached identity
and opens the dictionary to confirm that it is readable.

A `schema` block can declare `map` values, and an unknown type name is reported
by name. A metadata map key that is not an identifier, such as `markdown-it-py`,
fails compilation; 0.5.1 published it cut at the first such character.
`ling coverage --where` reports section labels the corpus cannot supply, as
`matches` and `summarize` do. With GiNZA, the spaCy adapter accepts text that
contains a comma.

The Harbor evaluation harness and its task images moved to the
`lingrep-harbor` repository.

Adapter wheels follow the 0.6.0 release version. Upgrading `ling` does not
require new analyzer bundles, and prepared corpora remain usable while their
format is supported. Preparing a new bundle with the 0.6.0 wheels changes its
analyzer identity and the identities of corpora prepared with it.
