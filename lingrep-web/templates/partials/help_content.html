Help with analysis and patterns

Frequencies

When count tables are configured, use Frequencies to count entries under document conditions. Occurrences count matches; documents count the documents containing them. Open an entry to inspect its charts and concordance lines. Documents with several metadata values can contribute to several bars.

Compare

Choose two document selections from the same corpus and catalog. Compare shows counts, rates and log-likelihood scores for their entries. The selections can overlap; the page reports their shared documents and tokens. Check the scope descriptions before interpreting a difference.

Download results

After a corpus search completes, Download results in this search scope writes an Excel workbook for the accepted search scope. Filtering or paging the displayed concordance does not narrow this export. The About sheet records the scope, overlap policy and any row truncation. If the search fails, previous completed results remain available for download.

CLI commands

Frequencies and Compare show commands for the same query over your local count table, corpus and catalog. The view’s display sorting and text filter are separate. Run relative paths from their common parent directory; replace TABLE.lingtable, CORPUS.lingcorpus and CATALOG.lx with your local paths when shown. Copy a page link to preserve its browser controls and selections.

pattern, or a definition without a keyword, produces matches. fragment defines a reusable pattern; set defines a set of values. Neither produces matches.

Token predicates

Use =, !=, in, not in, and /regular expressions/. Combine constraints inside a token with &.

ATTR near WORD >= 0.6 matches tokens whose ATTR value has a cosine similarity to WORD of at least 0.6. not near matches other values. Neither matches tokens without ATTR. A word-vector file is required. Check matching values on the Similar Words page.

Composition

Separate expressions with whitespace to match them in sequence. Use | for alternatives, parentheses for grouping, and @NAME to reference a declaration. Quantifiers are ?, *, +, and {n,m}.

Captures and comparison

(?<name> ...) captures a token span. same_as($name, by=ATTR) matches the same sequence of attribute values as that capture. ATTR can be any token attribute; the default is text.

Boundaries and assertions

^ and $ mark sentence boundaries. preceded_by(E) tests whether E ends at the current position; followed_by(E) tests whether E starts there. Neither advances the position. not_preceded_by(E) and not_followed_by(E) negate these tests. Bodies may match variable-length or empty spans, but cannot contain captures or same_as.

Dependency graphs

A where clause constrains basic dependency edges between captures. Enhanced edges use -[enhanced labels]->, may introduce a word or decimal empty node with (?<name> [test]), and may name the exact edge with as $edge. Every graph component requires a surface capture anchor; each complete assignment is one match.

Pattern editor

The pattern editor highlights lingrep patterns syntax and checks it as you type. Hover any attribute, value, @reference, or $capture for its documentation; typing same_as( shows the call signature inline with the active argument underlined.
